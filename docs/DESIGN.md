# Design system
Visual thesis: a contemporary campus noticeboard with editorial typography, ink-black navigation, warm paper surfaces, and a restrained vermilion accent. Event posters are typographic, category-specific graphic compositions; no stock photography or false campus imagery.

Tokens: paper #f7f7f2, surface #ffffff, ink #202a28, muted #606c67, border #dce0d8, accent #c4472c, green #2f624b. Body system sans-serif; display Georgia for selected headings. 4px spacing rhythm, 1200px content width, 6px controls and 10px card corners. Body 16px, metadata 14px, eyebrow 12px. Headers establish hierarchy without enormous heroes. Borders divide real sections; cards are for events, not every paragraph.

Navigation uses real links with active states. Forms group identity, schedule, and registration, with inline errors and summary feedback. Buttons have explicit progress/disabled states. Tables scroll within their region on mobile. Mobile navigation wraps into a compact menu; grids collapse; detail booking follows event identity. Focus outline 3px; 44px touch targets; reduced motion respected. Semantic headings, labelled fields, live status/error regions. No toast for navigation.
